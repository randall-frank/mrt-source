| The crack research staff at Mr TrashCan just uncovered a new gem.  Previously we announced the "Heresy" T.I.M.E Stories expansion that found a number of fans on Board Game Geek.  The developers alluded that this was part of a planned trilogy, but they have been quiet... until now.  The long anticipated followup is now available to play.  Now, it is no longer a formal T.I.M.E Stories expansion, but rather a work of interactive fiction which you can play directly in your browser.  Our staff has given it a run and it starts right where the previous story ends.  It can be played stand-alone, but ideally one should have played the first expansion.  
| Anyway, the game is online at: https://heresy.mrtrashcan.com/pages/heresy2.html.  The overall story starts here: https://heresy.mrtrashcan.com.  Even the source code to both stories is available on github (see the links at the bottom of that last URL).
